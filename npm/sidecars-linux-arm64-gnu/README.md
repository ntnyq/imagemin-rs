# `@imagemin-rs/sidecars-linux-arm64-gnu`

Prebuilt image codec sidecars for `imagemin-rs` on Linux ARM64 with glibc.

This package is installed automatically as an optional platform dependency. It contains pinned
cwebp 1.6.0, MozJPEG cjpeg 4.1.1, and MozJPEG jpegtran 4.1.1 executables, their provenance
manifests, and complete third-party license texts.
