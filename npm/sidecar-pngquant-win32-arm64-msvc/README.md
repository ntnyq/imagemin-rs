# `@imagemin-rs/sidecar-pngquant-win32-arm64-msvc`

Prebuilt pngquant 3.0.3 sidecar for `imagemin-rs` on Windows ARM64.

This optional GPL-3.0-or-later package contains the executable, provenance manifest, complete
pngquant/libimagequant license texts, and corresponding source/build materials under `sources/`.
The source set includes every registry archive in the pinned Cargo lockfile.

`sources/source-manifest.json` hashes every included material. The matching immutable
`imagemin-rs` Git tag and GitHub Release provide duplicate source copies.
