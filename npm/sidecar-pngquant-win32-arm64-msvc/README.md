# `@imagemin-rs/sidecar-pngquant-win32-arm64-msvc`

Prebuilt pngquant 3.0.3 sidecar for `imagemin-rs` on Windows ARM64.

This optional GPL-3.0-or-later package contains the executable, provenance manifest, exact source
references, and complete pngquant/libimagequant license texts.

The matching `imagemin-rs` GitHub Release attaches the verified source archives and SHA-256
manifest used to build this executable.
