# WebP fixtures

- `rgb-tiff.hex` is a deterministic 64×48, uncompressed, little-endian RGB TIFF generated by
  `tasks/generate-webp-fixtures.mjs`. It exercises the fourth input format accepted by
  `imagemin-webp@8`/cwebp without relying on an opaque binary fixture.

Existing PNG, APNG, JPEG+EXIF/ICC and grayscale fixtures are reused for WebP conversion tests.
