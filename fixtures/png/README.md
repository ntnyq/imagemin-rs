# PNG fixtures

`gradient.hex` is generated by
`cargo run -p imagemin --example generate_png_fixture`. It is a 32×24 RGBA
gradient/checker image with semi-transparent pixels and a `tEXt` metadata
chunk. Hex text keeps the binary reviewable and reproducible.

`pngquant-rgba.hex` is generated by
`cargo run -p imagemin --example generate_pngquant_fixture`. It is a 128×96
RGBA color field with transparent edge ramps, thousands of source colors and a
`tEXt` chunk. The larger corpus makes palette quality and size regressions
observable without storing opaque binary data.

`animation.hex` is generated by
`cargo run -p imagemin --example generate_apng_fixture`. It contains two RGBA
frames, a finite three-play loop and distinct frame delays for APNG no-op
conformance.
