# GIF fixtures

`animation.hex` is a deterministic in-repository fixture generated by
`cargo run -p imagemin --example generate_gif_fixture`. It contains eight
full-canvas frames, finite loop count `3`, per-frame delays `1..8`, two moving
colors and a comment extension. Hex text keeps the fixture reviewable in Git;
tests decode it before use.

The partial-frame, transparency, Background/Previous disposal and malformed
resource-limit cases are generated directly in
`crates/imagemin-codec-gif/tests/giflossless.rs`
so the exact structure remains visible beside the conformance assertions.
