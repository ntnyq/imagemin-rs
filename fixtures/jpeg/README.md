# JPEG fixtures

`color-metadata.hex` is generated by `node tasks/generate-jpeg-fixture.mjs`.
It is a 96×64 baseline 4:2:0 JPEG with deterministic high-frequency color,
EXIF orientation 6, a synthetic ICC APP2 payload and a comment marker. The
hex representation keeps marker-level changes reviewable and reproducible.

`grayscale.hex` is generated by the same task from deterministic PGM pixels.
It covers one-component baseline/progressive handling without relying on an
external copyrighted corpus.
